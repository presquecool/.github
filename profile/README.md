# presque.cool

Atelier d'applications, de jeux et d'art génératif. Chaque projet est
petit, fini, et se visite en une minute.

Non commercial : pas de publicité, pas d'abonnement, rien à vendre.

**[Voir le catalogue](https://presque.cool/)**
